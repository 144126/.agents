# Search-Net Skill

Triggers on 'sn'. Looping web search that returns simple, concise answers.

## When to Use

Use for quick factual questions, current info, or anything you want confirmed by the web without a research report.

## How to Use

Include 'sn:' followed by your question:
- "sn: what time is it in London"
- "sn: latest price of Bitcoin"
- "sn: is it raining in Seattle right now"

The skill keeps searching until it's sure of the answer, then gives you a short direct response.
