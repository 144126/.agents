# Research

```bash
~/.agents/skills/research/bin/research.ts "<question>"
```

Writes `~/search/<slug>.md` — Corroborated / Single / Unchecked + Sources. Gate: quote verbatim in source; every number in claim in quote else Unchecked.

Always add angles for core psychology and evolution: mate choice, status, costly signals, parental investment.
