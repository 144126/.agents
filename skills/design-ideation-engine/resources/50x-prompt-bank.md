# The 50× Concept Generation Prompt Bank

Use these prompts during Step 4 (Divergent Sprint) to keep the ideas flowing when you or the user get stuck.

---

## ROUND 1: Literal (10 concepts)

Generate the most obvious, direct, expected solutions first. Get them out of your system.

1. "What would the most straightforward version of this look like?"
2. "What's the industry-standard pattern for this type of project?"
3. "If a competent but uninspired designer solved this, what would they do?"
4. "What format does the audience expect to see?"
5. "What would make this feel 'professional' to someone outside design?"
6. "What's the default template, but executed perfectly?"
7. "What would this look like if the client described it themselves?"
8. "What's the most recognizable convention in this space?"
9. "What would make this feel familiar and safe?"
10. "What's the 'boring' solution — and how do we make it not boring?"

---

## ROUND 2: Opposite (10 concepts)

For each literal concept from Round 1, generate its opposite.

1. "What's the exact opposite layout from concept #1?"
2. "If competitors all do A, what does Z look like?"
3. "What if the primary interaction is reversed?"
4. "What if the visual hierarchy is inverted?"
5. "What if less is actually MORE than what competitors do?" (not minimalism — super-saturation)
6. "What if it looked like it belonged in a completely different industry?"
7. "What if the format was wrong deliberately?" (e.g. poster as website, book as app)
8. "What if the user had to work for it?" (deliberate friction)
9. "What if there was NO navigation at all?"
10. "What if it was silent — no animations, no interactive elements, static as a photograph?"

---

## ROUND 3: Cross-domain (10 concepts)

Apply specific cross-domain analogies. Use the analogy catalog.

1. "Design this as if it were a [hotel lobby] — what changes?"
2. "Design this as if it were a [Japanese garden] — what's different?"
3. "Design this as if it were a [protest poster] — what's the visual language?"
4. "Design this as if it were a [wine label] — what's the attitude?"
5. "Design this as if it were a [museum exhibit] — how does the user move through?"
6. "Design this as if it were a [sports broadcast] — what's the energy?"
7. "Design this as if it were a [fine jewelry display] — what's the pacing?"
8. "Design this as if it were a [coffee shop interior] — what's the feeling?"
9. "Design this as if it were an [escape room] — what's the user doing?"
10. "Design this as if it were a [passport] — what's the level of detail?"

---

## ROUND 4: Constraint-born (10 concepts)

Use the exact constraints from Step 3 to force ideas.

1. "Start with ONLY the technical constraint — what's the first idea this restriction produces?"
2. "Start with ONLY the aesthetic constraint — what's banned becomes a creative opportunity how?"
3. "Start with ONLY the conceptual constraint — what single rule generates an entire system?"
4. "Combine technical + aesthetic — what emerges from the friction between them?"
5. "Combine aesthetic + conceptual — what unexpected approach comes from both?"
6. "Combine technical + conceptual — what's the simplest version of this?"
7. "Now, break one constraint deliberately — which one? What does that unlock?"
8. "What if the constraint was the FEATURE — make the limitation visible and celebrated?"
9. "What if you added ONE MORE constraint — what's the extreme version?"
10. "What if the constraint was the ENTIRE concept — the restriction IS the idea?"

---

## ROUND 5: Absurd Stretch (10 concepts)

Mine the "dream" answer from the Brief Worksheet. Go too far, then pull back.

1. "What would you build if budget was unlimited?"
2. "What if a user could only interact with TWO elements on the entire page?"
3. "What if the entire design changed based on time of day or weather?"
4. "What if the site was entirely type — no images, no illustrations, no icons?"
5. "What if the site was entirely image — no more than 10 words total?"
6. "What if it was a single scroll that never ended — infinite narrative?"
7. "What if the site 'remembered' the user and changed over multiple visits?"
8. "What if the design was procedurally generated — different every visit?"
9. "What if there was no screen — the design existed in physical space?"
10. "What if the design was intentionally ugly, and that was the point?"

---

## Unstick Prompts (use when stuck mid-round)

| Situation | Prompt |
|-----------|--------|
| Ideas feel same-y | "Change ONE variable from the last concept — only one — and see where it goes" |
| Can't think of anything | "Describe the worst possible idea for this project. Now take one element from it and make it good." |
| Repeating yourself | "For the next 3 concepts, you can ONLY change the color/typography/layout — pick one dimension and exhaust it" |
| Too safe | "What idea scares you most? The one you'd be embarrassed to show? That's the next concept." |
| Too wild, not grounded | "Take the wildest idea so far. Now strip away 50% of its complexity. What remains?" |
| Running out of steam | "We have 5 more to go. For the next 2 minutes, write one-word concepts only. No sentences. Then expand them." |
| User is resisting | "We're not committing to anything yet. These are discarded after Step 5. Nothing here needs to be good." |
| Lost the brief | "Read the Inverted Brief Statement out loud. What's the ONE thing it demands that we haven't tried yet?" |
