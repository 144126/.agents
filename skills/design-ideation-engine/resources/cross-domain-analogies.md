# Cross-Domain Analogy Catalog

When you need to find cross-domain inspiration, use this catalog to find analogies. For each design problem type, look at how the listed domains solve the same emotional/functional challenge.

## If the emotional goal is: INSTANT CREDIBILITY / TRUST

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Hotel lobby architecture | Gradual reveal, sightlines that build anticipation, material hierarchy (marble = important, carpet = transitional) | Scroll-triggered reveal; material/texture changes signal section importance |
| Law firm office design | Restrained palette, symmetry, intentional negative space, nothing extraneous | Ruthless reduction — remove everything that doesn't signal authority |
| Passport / currency design | Ultra-detailed micro-typography, intricate patterns that reward close inspection | Dense, beautiful micro-details that reward zoom/attention |
| Watchmaking (e.g., Patek Philippe) | Visible craftsmanship through skeleton cases, exhibition backs | "Show the work" — expose the structure, make the grid visible, celebrate the system |
| Banknote design | Latent imagery, color-shifting elements, layered security patterns | Interactive reveal elements — scroll to uncover hidden details |

## If the emotional goal is: PLAYFUL DISCOVERY / DELIGHT

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Museum exhibit design | Narrative journey, objects revealed in sequence, text as complement not driver | Content-first scrolling with elements appearing as "exhibits" |
| Escape room UX | Deliberate friction, hidden mechanisms, satisfying click-states, multi-step reveals | Micro-interactions that reward exploration; hidden easter eggs in the UI |
| Children's book layout | Pace variation (double-page spread vs page-turn reveals), typography as image, interactive flaps | Variable layout grid that changes rhythm between sections; hover states as "flaps" |
| Game level design (Nintendo) | Tutorial-by-play, reward curiosity, gentle failure, escalating complexity | Onboarding that teaches by doing, not by telling |
| Carnival / fairground design | Color as signal (bright = exciting), sound cues, spectacle-as-navigation | Bold animated transitions between sections; color-coded navigation zones |

## If the emotional goal is: CALM / SERENITY / TRUST

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Japanese garden design | Borrowed scenery (shakkei), controlled views, path-as-experience, asymmetry | Compositions that "borrow" from the content — let content dictate layout; asymmetric but balanced |
| Spa / onsen design | Transition zones (locker → quiet room → treatment), sensory stripping, material warmth | Generous whitespace as transition zones between content sections; warm material palette |
| Meditation app flows (e.g., Calm) | Extreme reduction of choices, no friction states, haptic feedback as grounding | Single-action screens; ambient micro-motion that mimics breathing |
| Tea ceremony (chanoyu) | Choreographed sequence, intentional imperfection (wabi-sabi), seasonal awareness | Deliberately imperfect typography spacing; content that changes with time/season |
| Private banking lounge | Privacy through spatial design, no visible technology, human-scale furniture | Anti-tech visual — hide the chrome, warm colors, soft shadows, human-scale components |

## If the emotional goal is: ENERGY / EXCITEMENT / URGENCY

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Sports broadcast graphics | Dynamic typography, color-coded data, real-time updates, layered information | Kinetic typography; data visualization as hero element; live-feed aesthetics |
| Music festival branding | Extreme scale contrast, clashing colors, typography as texture | Oversized elements that overflow viewport; purposefully jarring color combinations |
| Nightclub interior design | Lighting zones, material contrast (velvet/concrete), hidden spaces, sensory overload | Dark mode with strategic bright accents; texture mixing; reveal-as-you-scroll layout |
| Action film editing | Quick cuts, color grading shifts, sound design as storytelling | Rapid section transitions; scroll-velocity-triggered transformations |
| Protest poster design | Bold typography, high-contrast, single message per poster, repeatable format | One-message-per-viewport; high-contrast palette; repeatable grid with variable content |

## If the emotional goal is: SOPHISTICATION / LUXURY / EXCLUSIVITY

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Haute couture runway | Reveal-as-performance, one dramatic piece per look, restrictive beauty | Each screen as a "look" — one bold element per viewport |
| Wine label design | Minimal text, embossed texture, paper choice as signal, provenance as story | Tactile texture suggestions through CSS; story-as-design (provenance visible) |
| Minimalist architecture (Tadao Ando) | Light as material, concrete as canvas, void as space, precision of joinery | Negative space as active design element; light/dark as material; pixel-perfect spacing |
| Art gallery curation | White space, single artwork per wall, lighting direction, label as interface | Generous margins; one focal element per section; minimal interface |
| Fine jewelry display | Dark backgrounds, spot lighting, sparse arrangement, each piece has space to breathe | Dark mode with dramatic single highlights; sparse layouts with breathing room |

## If the emotional goal is: COMMUNITY / BELONGING / WARMTH

| Domain | What They Do | Design Move to Steal |
|--------|-------------|---------------------|
| Coffee shop interior | Visible human activity (barista at work), communal tables, imperfect materials, ambient noise | User-generated content as design element; imperfect/organic textures; real-time social proof |
| Community center design | Flexible spaces, visible infrastructure, welcoming threshold, bulletin board culture | Modular layouts that users can personalize; prominent community-generated content |
| Farmer's market signage | Hand-lettered, variable quality, personality over polish, seasonal rotation | Hand-drawn/illustrated elements; intentionally varied typography; rotating content |
| Intimate music venue | Shared experience focus, artist-audience proximity, ritual elements (darkness → performance light) | Progressive reveal — dark entry → dramatic content reveal; scroll-as-curtain |

## Quick Reference: Problem → Domain

| If your problem is... | Look at... |
|----------------------|------------|
| Information overload | Museum label design, airport signage systems, data dashboard for air traffic control |
| User doesn't know where to start | Toy instruction design, IKEA assembly guides, video game tutorials by play |
| Need to show hierarchy | Military rank insignia, subway maps (Harry Beck), heraldry |
| Need to build trust fast | Restaurant menu design, doctor's office reception layout, hotel room first-impression design |
| Need to convey scale | Map design (different projections), architectural section drawings, telescope control interfaces |
| Need to convey speed/speed | Motorsport timing screens, F1 steering wheel interfaces, bullet train interior design |
