# Search-Net-X Skill

Triggers on 'snx'. Multi-pass deep research with citation tracking and structured breakdowns.

## When to Use

Use for deep research, analysis, comparisons, topics needing verification across multiple sources. Not for quick answers.

## How to Use

Include 'snx:' followed by your research query:
- "snx: what is the state of AI regulation in 2026"
- "snx: compare PostgreSQL vs SQLite for edge deployment"

The skill will run 8-20+ searches, track sources, and return a comprehensive research breakdown.
